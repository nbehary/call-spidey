# M0 — Orientation

**Goal:** an app you created runs on your iPhone, the `ios/` skeleton exists
in the repo, and we know which iOS 26 features your Xcode can build.

No porting yet. Signing and device setup are where beginners most often
stall, so clear them while the app is trivial.

## What you already know, and its iOS counterpart

| Android | iOS |
|---|---|
| Android Studio | Xcode |
| Gradle module | Target (inside a project) or a Swift package |
| Build variant and run configuration | Scheme |
| `build.gradle.kts` | Project settings (in Xcode) or `Package.swift` |
| `AndroidManifest.xml` | `Info.plist` and the target's settings |
| `applicationId` | Bundle identifier |
| Debug keystore, automatic | Signing team and provisioning profile |
| USB debugging toggle | Developer Mode on the phone |
| `adb install`, `adb logcat` | Run from Xcode; the debug console |
| Emulator (AVD) | Simulator |
| `./gradlew test` | `swift test` (package) or `xcodebuild test` (app) |

## Steps

1. **Mac setup.** Confirm Xcode opens and has an iOS 26 platform installed
   (Xcode's Settings, Components). Install Claude Code on the Mac and clone
   this repo there.
2. **Apple ID.** Add your Apple ID in Xcode's Settings under Accounts. This
   gives you a free "Personal Team".
3. **Throwaway app.** Create a new iOS App project (SwiftUI) somewhere
   outside the repo. Run it in the Simulator.
4. **On the phone.** Connect the iPhone. Turn on Developer Mode
   (Settings, Privacy & Security). In the target's Signing & Capabilities
   tab, pick your Personal Team. Run. The first launch needs you to trust
   your developer certificate on the phone (Settings, General, VPN & Device
   Management).
5. **Change something.** Edit the text in `ContentView`, add a button that
   changes it, and run again. Find the canvas preview.
6. **Capability check.** In the throwaway app, find out whether these build
   and whether the phone reports them available. Record the answers in
   `PROGRESS.md`:
   - the Foundation Models framework (on-device language model)
   - the iOS 26 speech recognition API (`SpeechAnalyzer`)
   - Apple Intelligence switched on in the phone's Settings
7. **Repo skeleton.** In the repo, create:
   - `ios/SpideyCore/`: a Swift package of type library, created from the
     command line. Run its generated test with `swift test`.
   - `ios/CallSpidey/`: a new iOS App project, bundle ID
     `dev.nate.spideycall`, deployment target iOS 26, portrait only.
   - Add `SpideyCore` to the app as a local package dependency.
8. **Ignore rules.** Add Xcode's per-user and build files to `.gitignore`.
